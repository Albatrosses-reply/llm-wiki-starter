1. `index.md`를 읽고 관련 페이지 3~10개를 고른다. 볼트 전체를 훑지 않는다. 더 찾을 때는 `notes/sources` 폴더만 검색한다.
2. 고른 페이지의 요약·결과·사람 섹션을 읽고 답한다. 주장마다 `[[citekey]]`를 단다. 페이지에 없는 내용은 "위키에 없음"이라고 쓴다.
3. 원문 확인이 필요하면 그 페이지의 PDF 쪽 번호를 알려 주고, 사람이 Zotero에서 열어 보게 한다.
4. 사람이 "저장"이라고 하면 답을 `notes/concepts/<slug>.md`(개념 정리) 또는 `notes/syntheses/<slug>.md`(비교·리뷰)로 저장하고 `wiki index`를 실행한다.
